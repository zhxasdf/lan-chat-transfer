# LAN Chat Transfer

局域网多人聊天与文件传输课程项目。当前版本使用 **Python / FastAPI + Vue 3 / Vite**，已实现注册登录、在线成员、公共群聊、一对一私聊、群聊与私聊文件传输、账号级文件权限、聊天记录持久化与历史加载、离线私聊、文件持久化与删除、应用层心跳与自动重连。

账号、会话、聊天记录、文件信息和已读位置保存在SQLite，文件内容保存在磁盘；正常重启后仍可下载。敏感词检测已按用户决定取消，不在项目范围内。当前必做功能已全部实现，剩余工作为课程报告、答辩材料和最终验收。

## 环境与安装（Windows PowerShell）

使用Python 3.11和Node.js 24.12以上。已在Python 3.11.9、Node 24.22.1、npm 11.19.1上验证。以下命令均从仓库根目录开始执行；使用`npm.cmd`可避免PowerShell阻止`npm.ps1`。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r backend/requirements-dev.txt
Set-Location frontend
npm.cmd ci --cache .npm-cache
Set-Location ..
```

后端主依赖固定在`backend/requirements.txt`，测试依赖固定在`backend/requirements-dev.txt`；完整的本机已验证依赖快照见`backend/requirements-lock.txt`。需要复现快照时，用`-r backend/requirements-lock.txt`替换上述后端安装参数。若默认Python源连接失败，可追加`--index-url https://pypi.org/simple --timeout 15`重试。

数据库使用SQLite，由Python标准库提供，无需额外安装服务；首次运行自动在`backend/data/chat.db`建表，文件内容保存在`backend/data/files/`，均已被Git忽略。数据库路径可用`LAN_CHAT_DB`配置，文件目录默认是数据库同目录的`files/`，可用`LAN_CHAT_FILES`覆盖。本轮按新数据库与新文件目录设计，不提供旧数据迁移；不要共用同一个文件目录运行多个服务进程。

手动重置测试环境时，先停止后端，再同时清空测试数据库和文件目录，重新启动并注册账号。代理不会自动清空现有开发数据。验证持久化时应保留数据库与文件目录，重启后检查下载内容。

## 快速运行：构建后只启动一个服务

```powershell
Set-Location frontend
npm.cmd run build
Set-Location ..
.\.venv\Scripts\python.exe -m uvicorn backend.main:app --host 0.0.0.0 --port 8000
```

本机打开 <http://127.0.0.1:8000>。首次使用先注册账号（用户名3～20个字符，密码8～64个字符），之后用同一账号登录。模拟多人聊天时，请使用不同浏览器、普通窗口与隐私窗口等独立的浏览器环境，分别登录不同账号；同一浏览器的普通标签页会共享登录账号。点击“在线成员”里的其他成员可发起一对一私聊，点“← 公共频道”切回群聊。刷新页面后会恢复登录状态并重新加载历史消息。使用Ctrl+C停止服务。

## 聊天记录与历史

- 群聊、私聊消息和文件卡片都会写入 SQLite。进入公共频道或某个私聊时自动加载最近 50 条，向上滚动到顶部会继续加载更早的消息。
- 刷新页面或重新进入聊天室后，登录状态和历史消息都会恢复；退出登录不会删除历史记录。
- 私聊历史按账号对查询，只有对话双方能看到；第三方即使知道对方账号，也查不到两人的私聊。
- 文件卡片与文件内容均会保留，重启后仍可按账号权限下载；发送者删除文件后保留卡片，显示“文件已删除”。磁盘文件丢失或启动检查发现损坏时显示“文件不可用”。
- 历史按时间正序展示，服务端用自增序号分页，避免同一时间戳的消息乱序。

## 离线消息与未读

- 在侧栏“发起私聊”输入完整用户名并点击“查找账号”，可给已注册的离线账号发送文字或文件；也可从“最近私聊”进入已有会话。手机窄屏需先展开“在线成员”。
- 对方离线不影响发送，服务器先保存再确认，发送者看到“对方离线，消息已保存”；这不是对方已收到或已读的回执。接收者上线后从最近私聊的未读提示进入会话查看和下载。
- 登录时恢复最近私聊及未读数。仅登录、刷新或后台接收不会清除未读；打开私聊后，当前可见页面成功加载并渲染的连续消息范围会自动标为已读，同账号标签页同步未读状态。这表示页面已展示，不保证用户逐条阅读。
- 有未读时先从最早未读位置加载50条；更多消息通过“加载后续消息”继续展示，每次仅确认已加载的连续范围，未加载的后续消息保留未读。向上滚动仍可查看更早历史。
- 未读状态保存在账号级数据库中，退出或重启不会丢失。只统计私聊收到的文字和文件卡片，群聊不提供持久化未读数。发送失败的消息不会自动重发，重连后以历史记录为准；没有发送者侧的已读回执。

## 心跳与自动重连

- 客户端每 20 秒发送一次应用层心跳，服务端回复 `pong`；服务端超过 45 秒没有收到该连接的任何消息时会关闭它并更新在线状态。
- 意外断线（网络中断、服务重启、心跳超时）后，页面显示“正在重连”并按退避间隔自动重连，不需要手动刷新；重连成功后恢复在线成员和当前会话的历史消息，并补齐断线期间遗漏的消息。
- 主动退出登录、会话失效（服务端关闭码 4001）不会自动重连，页面回到登录页；关闭浏览器标签页也不会重连。
- 重连间隔从 0.5 秒开始指数增长，最长 15 秒；网络恢复后通常几秒内自动恢复。
- 心跳参数目前是前端常量与服务端默认值，没有界面设置；消息不会自动重发，以数据库历史为准。

## 账号与登录

- 数据库保存用户名、密码哈希（scrypt加盐）和登录会话；密码只以哈希形式存储，不保存明文。
- 登录成功后令牌保存在浏览器 localStorage，有效期7天；刷新页面会用令牌自动恢复登录。退出登录会同时删除服务端会话。
- 同一账号可以在多个标签页或设备同时登录，在线列表和人数按账号去重；群聊、私聊和文件卡片同步到该账号的所有在线标签页。首个连接上线时提示进入，最后一个连接断开时提示离开，关闭单个标签页不会让账号离线。
- 同一浏览器、同一网站的标签页共享登录状态，新标签页自动恢复登录；退出登录会同步退出共享该会话的标签页，并关闭相应服务端连接。其他浏览器或设备独立登录的会话继续有效。
- 没有密码找回、邮箱验证、验证码或登录失败次数限制，只适合课程演示，请勿使用真实密码。
- 账号只解决“你是谁”，局域网内仍为明文HTTP/WebSocket，不要用于传输敏感数据。

## 发送和下载文件

- 在公共频道或私聊中点击“＋ 发送文件”，选择一个文件后自动上传，最大 **20 MiB（20,971,520字节）**，允许空文件。一次上传一个文件，支持进度和取消；文字聊天可以继续使用。
- 上传目标固定为选择文件时所在的会话，之后切换频道不会改变目标。上传完成后通过聊天消息出现文件卡片，点击“下载”保存；卡片出现表示服务器已接收文件，不是对方已下载的回执。
- 公共频道文件允许任意已登录账号下载；私聊文件只有原发送者和接收者的账号能下载，不能只凭文件ID访问。退出后重新登录同一账号仍可下载旧的私聊文件；其他账号即使使用同样昵称也不行。
- 文件内容以随机ID存入固定目录，原文件名仅用于展示。数据库保存SHA-256、大小、时间、发送者、接收者和状态；文件信息与卡片在同一事务中提交，成功后再通知客户端。
- 总容量256 MiB，上传时每个请求预留20 MiB，取消与失败释放预留；重启后恢复已用容量。默认长期保留，空间满后拒绝新上传，不自动淘汰旧文件。
- 只有发送者可以点击卡片“删除”；删除释放空间，双方历史卡片仍保留。其他人正在下载时暂时拒绝删除，请稍后重试。磁盘清理失败会提示重启后清理，已标记删除的内容不能继续下载。
- 启动时校验已保存文件的大小与SHA-256，并清理本存储目录中符合命名规则的未完成上传、无记录或已删除文件残留；不处理旧版本数据迁移。不做预览、断点续传或自动重试。取消时若卡片已出现，表示服务器已完成保存。

先构建前端、再启动Python服务。如果首次构建时Python已经在运行，构建完成后重新启动Python，使静态资源挂载生效。不要添加多个worker：当前在线连接只在单进程内共享。

## 开发：两个终端

终端一，在仓库根目录：

```powershell
.\.venv\Scripts\python.exe -m uvicorn backend.main:app --reload --host 127.0.0.1 --port 8000
```

终端二，在仓库根目录：

```powershell
Set-Location frontend
npm.cmd run dev
```

开发页面打开 <http://localhost:5173>。Vite将`/api`和`/ws`代理给8000端口。后端热重载会中断聊天连接，页面会自动重连并在恢复后加载历史。

## 局域网访问和双机验收

1. 按“快速运行”构建并启动服务，确保监听`0.0.0.0:8000`。
2. 用`ipconfig`查看服务器当前Wi-Fi或以太网的IPv4地址，例如`192.168.1.20`。
3. 同一局域网的手机或另一台电脑打开`http://192.168.1.20:8000`，注册或用已有账号登录。
4. 如果本机可访问、其他设备不行，检查是否同网、路由器是否启用访客网络/设备隔离，以及Windows防火墙是否允许实际Python进程通过当前网络类型使用8000端口。不要关闭整个防火墙。

这里的IP只是例子，不能直接照抄。用户已反馈手机与电脑在个人热点下聊天成功，并于2026年11月21日确认完成双设备群聊、私聊文件互传及下载内容核对。校园Wi-Fi访问超时，具体原因未最终确认。详细验证范围及剩余事项见[交接说明](交接说明.md)。

## 阅读代码与交接

- `backend/db.py`：SQLite建表、账号、密码哈希、登录会话和消息历史（含游标分页查询）。
- `backend/main.py`：应用入口、注册登录接口、WebSocket认证、应用层心跳与房间/连接管理。
- `backend/files.py`：持久化文件、容量恢复、上传下载、删除、残留清理与账号权限校验。
- `frontend/src/useChat.js`：登录状态、连接与消息状态、心跳与自动重连；`App.vue`和`components/`：页面与组件。
